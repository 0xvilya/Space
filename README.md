# SOLARIS — адаптивный Solar System Explorer

## Что оптимизировано
- Адаптивная раскладка для мобильных экранов, небольших телефонов, планшетов и широких мониторов.
- Canvas DPR ограничен: до 1.35 на телефонах и 1.75 на больших экранах, чтобы уменьшить нагрузку на GPU.
- Меньше звёзд и проще отрисовка на телефонах.
- Поддержка сенсорного перетаскивания и pinch-to-zoom двумя пальцами.
- Кнопки с удобными зонами нажатия, safe-area отступы для iPhone, клавиатурное управление на ПК.
- Уменьшение движения при включённом `prefers-reduced-motion`.
- Пауза анимации, когда вкладка скрыта.
- Без внешних библиотек, шрифтов, изображений и API-запросов.

## Публикация
Загрузите `index.html` и `README.md` в корень GitHub-репозитория. Затем **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

## Управление
- ПК: перетаскивание мышью, колесо для масштаба, стрелки для смены планет, пробел для паузы.
- Телефон: перетаскивание пальцем, щипок двумя пальцами для масштаба, панель планет снизу.
- Кнопки `+`, `−`, `⌂` для масштаба и сброса.
